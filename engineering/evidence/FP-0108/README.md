## Resolved ambiguities

1. **Before state.** Case 16 and the repository check together require `src/text/grapheme.zig` and `src/text/text.zig` to exist before the change. The before state therefore had both files, with no `GraphemeBoundaries` declaration in `grapheme.zig`. Every Zig case still failed to compile, and every compile error names a missing FP-0108 declaration or file.
2. **Case 4 at base.** The case first parses the unchanged case 2 fixture, so at base it fails with `ucd.parseFieldProperty is not a function`, as the contract states, before any `assert.throws` validator can wrap the error.
3. **Field-mode and binary-mode messages.** The messages are `the InCB line has no value`, `unknown value "Nope"`, `the InCB line has more than one value`, and `the binary property Extended_Pictographic takes no value`, each prefixed by `Fixture.txt line <n>: `. An `@missing` line is read in both modes. In binary mode, an `@missing` line that gives the property a value fails like a data line; `emoji-data.txt` has none.
4. **Extended_Pictographic default.** `emoji-data.txt` has no `@missing` line. The generator gives every unlisted code point false. The reference parser applies that default only after it finds the file's line 845, `# All omitted code points have Extended_Pictographic=No`, and it marks every code point as assigned by that default.
5. **Generated order.** `GraphemeClusterBreak` and `IndicConjunctBreak` follow `IndicPositionalCategory` in `tables.zig`, and `extended_pictographic_ranges` follows `script_extension_ranges`. Every existing table keeps its bytes; only the header and the appended tables differ.
6. **Conformance test location.** `@embedFile("../unicode/ucd/auxiliary/GraphemeBreakTest.txt")` compiles from `src/text/grapheme_test.zig`, so the test stays under `src/text/`.
7. **Failure reports.** Cases 11 to 15 report every failing line, row, seed, or input before they fail, instead of stopping at the first one, so each control shows every line that the contract names. A conformance failure prints its line number, the expected boundaries, and the found boundaries.
8. **Work bound.** `GraphemeBoundaries` decodes each code point once and keeps the next code point's properties after it finds a boundary. The only repeated read is the code unit after a lone high surrogate, which is read once as a failed pair check and once as its own code point. Every unit is therefore read at most twice, which keeps `units_read` within 2 × `b` + 4 after a boundary `b` and within 2 × the length at the end.
9. **State.** `linker` holds when `InCB=Linker InCB=Extend*` ends at the previous code point. `pictographic` holds when `ExtPict GCB=Extend*` ends there, and `pictographic_zwj` holds when the previous code point is a ZWJ that follows such a sequence. `odd_regional_indicators` holds when an odd RI run ends there. Before the first code point, all four are false.
10. **M2.** The control adds a `consonant` flag for `InCB=Consonant [InCB=Extend InCB=Linker]*` and sets `linker` only after it, following the Unicode 15.1 rule that revision 49's Modifications section replaced.
11. **Mutation commands.** The controls run the FP-0108 cases through `zig test --test-filter FP-0108` on both roots, which compiles the same sources as `zig build test` but runs only the FP-0108 tests. M7 also runs `node tools/ucd.test.mjs`, which holds controller case 1.
12. **Case 5 frozen values.** Case 5 compares the `unicode` entry of `specs/corpora.json` with its committed field values, and the source digests with the contract's values, instead of reading the base commit through Git.
13. **Capability wording.** The `unicode-remaining-data` summary names word and sentence segmentation, emoji sequences, the conformance files other than `GraphemeBreakTest.txt`, and the properties of `DerivedCoreProperties.txt` and `emoji-data.txt` other than Indic_Conjunct_Break and Extended_Pictographic.
14. **Source registry.** `specs/sources.json` S58 said "the eight imported UCD files", which this import made false, so it now says "twelve". `specs/` is writable for this task, and `specs/corpora.json` is untouched.
